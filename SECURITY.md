# Security and responsible use

This repository can generate significant traffic and includes protocol-experiment code. It must only be used against systems you own or where you have explicit written authorization and a defined test window. Never aim it at public services, third-party infrastructure, or networks without permission. Stop immediately if a target shows instability, errors, or unexpected impact.

Do not paste targets, credentials, customer data, or internal topology into public issues. Report code defects privately through the maintainer's GitHub contact channels.
